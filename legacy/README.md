# PostFlow - Générateur de posts LinkedIn

Application web légère pour générer des posts LinkedIn originaux avec un style humain.

## Lancer le projet

1. Ouvre le dossier du projet.
2. Lance un serveur local (exemple Python):

```bash
python3 -m http.server 8080
```

3. Ouvre [http://localhost:8080](http://localhost:8080).

## Fonctionnalités

- Génération de 3 variantes de posts
- Structures inspirées de frameworks marketing (AIDA, PAS, Story)
- Réglage du ton, objectif, audience et niveau d'énergie
- CTA personnalisable
- Hashtags automatiques
- Copie en un clic
